RAG Mode Addendum:
- Use get_relevant_capabilities for capability discovery; do not use get_all_capabilities in RAG mode.
- Default top_k is 2. Use iterative deepening: start with top_k=2. If suitable capabilities are missing, increase by +1 (3, 4, 5, 6). If still not found, rephrase the query and restart at top_k=2. Avoid large jumps.
- Keep all baseline recipe and batching rules from the default prompt unchanged; this addendum is retrieval-specific only.
